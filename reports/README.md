# Datalog Health Reports Directory

This directory stores exported JSON telemetry reports generated by the **[Datalog Report Generator](../report-generator.html)**.

## How to Backup a Report Here:
1. Open `report-generator.html` in your browser and scan your COBB AccessPort `.csv` log.
2. Click **💾 SAVE AS JSON** to download `report_YYYY-MM-DD_HH-MM-SS.json`.
3. Move or copy the downloaded `.json` file into this `/reports/` directory.
4. Commit and push to GitHub:
   ```bash
   git add reports/
   git commit -m "Add datalog health report: [Date]"
   git push origin main
   ```

Each report contains complete extracted metrics (Boost, AFR, Timing Retard, Knock events, DAM, Fuel Pressure, Temps), calibration verdict, and timestamped out-of-spec incidents for version-controlled tuning history.
